## 🧠 Overview

This repository hosts the codebase and configuration files used in the ISSCC 2025 paper, describing a 1024-channel real-time online spike sorting chip. The system is optimized for ultra-low power and area efficiency and features:

- Event-driven spike detection
- Spatial feature extraction
- Online clustering via a Self-Organizing Map (SOM)-inspired method

---

## ⚙️ Requirements

- **MATLAB R2021a or newer**
- **Python with MEArec** (for dataset generation)


## 📊 Reproducing the Results

To replicate the experiments reported in the paper, follow these steps:

1. **Array Configuration**
   Configure MEArec to use a 32×32 electrode array using the following file:
   `MEArec/Array/WIREDOR32X32_36u.yaml`

2. **Template Generation**
   Generate spike templates with MEArec using the configuration file:
   `MEArec/TemplateConfig/WIREDOR_params.yaml`

3. **Recording Generation (5-Minute Dataset)**
   In the paper, we used a 5-minute synthetic dataset to evaluate spike sorting performance. This dataset was constructed by generating 25 recordings of 12 seconds each using:
   `MEArec/RecordingConfig/WIREDOR_recordings_params.yaml`
   All recordings use the same `templates_seed = 0` to ensure consistent neuron templates, while `spiketrains_seed` varies from 0 to 24 to produce different spike trains.
   The output files should follow this naming format:
   `*_0.h5`, `*_1.h5`, ..., `*_24.h5`
   These files are concatenated to create the final 5-minute dataset.

4. **Apply Wired-OR Processing**
   Process the generated recordings using the wired-OR compression by running:
   `WiredOR/WiredOR_MEArec.m`
   When running this script:

   * Select the first dataset file (e.g., `*_0.h5`) as input.
   * Ensure all dataset files (`*_0.h5` through `*_24.h5`) are located in the same directory.
   * Set the `numberOfDataSets` parameter to match the total number of segments (e.g., 25).
   * Adjust `wire_number` and `lsb` parameters to configure the compression level and resolution.

   The script generates an output file named `data.h5` in the same directory as the input files.

5. **Spike Detection**
   Use the script `SpikeDetection/SpikeDetection.m` to perform spike detection on the `data.h5` file generated by the Wired-OR processing.

   In the script:

   * Select the input `data.h5` file.
   * Customize detection parameters as needed:

     * `ampThreshold` — absolute amplitude threshold
     * `NEOThreshold` — nonlinear energy operator threshold
     * `preDetectionThr` — pre-detection threshold
   * To prepare results for subsequent steps, set `centralChannelDetection` parameter to `1`.

   The output file is `detection.mat`, saved in the same directory as the input data. The output filename encodes the NEO and absolute thresholds used during detection.

6. **Feature Extraction**
   Run the script `FeatureExtraction/FeatureExtraction.m` by selecting both the `detection.mat` file from spike detection and the `data.h5` file from Wired-OR processing as inputs.

   This step extracts spatial features from detected spikes and produces an output file named `Features.mat`. The output filename includes the NEO and absolute thresholds used during detection for easy reference.

7. **Clustering (Classification)**
   Execute `Classification/ClassificationTop.m` on the extracted features (`Features.mat`).

   During execution:

   * The number of iterations and active elements per iteration will be plotted to visualize clustering progress.
   * A result file named `Clusters.mat` will be generated, containing the final spike sorting output.
   * The output filename encodes the NEO threshold, absolute threshold, and `removeScale` parameter used during clustering for easy identification.
