# soft_loc 错分分析：不可分样本关系 & OSort 能否继续分开

数据：Hybrid Janelia 16ch，前 60s，**GT spike 时间**（隔离检测误差）。  
脚本：`python -m Spatial.experiments.analyze_soft_loc_errors --dataset hj --duration 60`

---

## 结论（先看这个）

1. **soft_loc 的错误高度集中在「同主通道 + COM 几乎重叠」的 unit 对**，尤其是 **unit 5 ↔ 21**（都在 ch14，Δcy≈0.002）。
2. **单独加 OSort Peak-FSDE 不能当全局方案**（oracle 仅 47.6%）——没有通道/位置信息时，很多单元主通道波形归一化后撞车。
3. **soft_loc + Peak-FSDE 拼接后可以继续分**：全局 oracle **91.6% → 93.0%**；soft_loc 的 117 个错里 **约 61% 被 combo 纠正**。
4. 同通道难分对 **5–21**：两两 oracle 从 soft **76.5% → combo 91.6%**，说明这对主要差在**波形形态**，空间足迹几乎一样。
5. 仍有一小撮 combo 也分不开（约 46/1394），包括 **25–62**（不同通道）和残存的 5–21 —— 空间+主通道 FSDE 仍不够时，需要更强的波形/多通道模板信息。

## soft_loc 错在什么关系上？

soft_loc 测试集 oracle：`acc=91.6%`，错误 **117 / 1394**。

| 错误类型 | 数量 | 占比 |
|----------|------|------|
| 预测成**同一主通道**的另一 unit | 75 | **64.1%** |
| 预测成**不同主通道**的 unit | 42 | 35.9% |

| … | | | | | | |

**典型不可分关系 = 共享电极 + 深度质心重合：**

| 混淆对 | #err | 同通道? | Δcy | 关系解读 |
|--------|------|---------|-----|----------|
| **5–21** | **70** | 是 (ch14) | **0.002** | 主导错误源：足迹几乎同一位置 |
| 25–62 | 10 | 否 (4 vs 6) | 0.112 | 邻通道、spread/sharp 接近，偶发串扰 |
| **43–63** | 5 | 是 (ch7) | **0.006** | 另一对同通道重叠（量更少） |
| 其余 | ≤4 | 多为否 | 较大 | 边界噪声 / 少数 outlier |

一句话：soft_loc 已经把「不同深度 / 不同主通道」的单元分得很好；**剩下的硬骨头是「住在同一电极附近、幅度足迹几乎一样」的成对单元**（HJ 文档里早就点名的 5/21、43/63）。

## 加入 OSort（Peak-FSDE）后还能不能分？

这里的 OSort 相关信息 = 主通道 64 点波形上的 **Peak-FSDE 5D**  
`[P, FDmax, FDmin, SDmax, SDmin]`（与 GeoOsort `FeatureExtractor` 一致，波形 max-abs 归一化）。

### 全局 GT-centroid oracle

| 特征 | Oracle |
|------|--------|
| soft_loc only | 91.6% |
| Peak-FSDE only | **47.6%**（很差） |
| soft_loc + Peak-FSDE（各维 z-score 后拼接） | **93.0%** |

Peak-FSDE 单独差，是因为它**丢掉了通道/深度**：归一化后只看波形形状，空间上远离的单元也可能撞车。它适合作为 **soft_loc 的补丁**，而不是替代品。

### soft_loc 错误被「救回」多少？

| | 数量 | 占 soft 错误 |
|--|------|----------------|
| soft_loc 测试错误 | 117 | 100% |
| 仅 FSDE 就能判对 | 37 | 31.6% |
| soft+FSDE 能判对 | **71** | **60.7%** |
| combo 仍错 | 46 | 39.3% |

### 难分对上的两两可分性（只拿这两个 unit 做 2-class oracle）

| Pair | soft 2-class | FSDE 2-class | soft+FSDE | 解读 |
|------|--------------|--------------|-----------|------|
| **5–21** | 76.5% | 83.9% | **91.6%** | 空间几乎不可分；波形能拉开；拼接最好 |
| **43–63** | 94.4% | 97.5% | **97.5%** | soft 已不难；FSDE 再抬一点 |
| 25–62 | 90.3% | 72.6% | 87.1% | 不是「缺波形」型；FSDE 帮不上，甚至干扰 |
| 多数异通道对 | >97% | 参差 | ≈ soft | soft 已够，FSDE 增益很小 |

## 机制总结

```text
soft_loc 可分区域
  └─ 不同主通道 / COM 深度明显分离
       → 再加 FSDE 收益很小

soft_loc 不可分核心
  └─ 同主通道 + Δcy ≈ 0（5–21, 43–63）
       → 足迹同一「山峰」
       → Peak-FSDE（主通道波形形态）可继续分
       → soft_loc + FSDE 是正确组合方式

仍难
  └─ 空间接近且波形也像，或异通道但特征重叠（如 25–62）
       → 需要更强信息（多通道波形 / 模板匹配），超出「主通道 FSDE」
```

---

## 对后续方法的建议

1. **1D 空间上限**：继续以 `soft_loc` 为空间主干，不要指望 Akhoundi angle。  
2. **要抠 soft_loc 剩下的 ~8%**：对同通道对引入 **OSort Peak-FSDE（或完整主通道波形距离）**，做 dual-metric（空间门控 + 波形距离）——与 GeoOsort dual-metric 方向一致。  
3. **不要**只用 Peak-FSDE 做全局聚类（HJ 上 oracle 会崩到 ~48%）。  
4. 若 combo 后仍盯着 5–21 / 25–62：下一步才是多通道模板或更长波形特征，而不是更复杂的纯空间标量。
